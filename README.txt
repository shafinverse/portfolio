SETUP (one time)
1. GitHub e ekta notun PUBLIC repository banao (jemon: portfolio).
2. Ei folder er shob file (index.html, admin.html, data, assets, uploads, .nojekyll) oi repo te upload koro.
3. Repo > Settings > Pages > "Deploy from a branch" > main / (root) > Save. 1-2 minute por website live hobe.
   Website: https://<username>.github.io/<repo>/        Admin: .../admin.html
4. GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate:
   Repository access = shudhu oi repo, Permissions > Contents = Read and write.
5. admin.html khule username, repo name, branch (main) ar token boshao > Connect & Load.
6. Content bodlao, file upload koro, tarpor "Save to GitHub" chaapo. ~1 minute e website update hoy.
Token kokhono kono file e likhe repo te rekhona.
